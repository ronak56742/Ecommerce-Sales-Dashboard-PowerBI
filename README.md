# 📊 E-Commerce Sales Dashboard | Power BI

## 🔍 Project Overview
This project presents an interactive **E-Commerce Sales Dashboard** built using **Power BI** to analyze sales performance, profitability, customer behavior, and category trends.

The dashboard helps stakeholders quickly identify:
- High-performing states and customers
- Monthly profit trends
- Category and sub-category contribution
- Payment mode distribution

---

## 🛠 Tools & Technologies
- Power BI
- Excel (Data Cleaning)
- DAX (Basic Measures)

---

## 📈 Key Metrics Analyzed
- Total Sales Amount
- Total Profit
- Quantity Sold
- Average Order Value (AOV)

---

## 📊 Visualizations Included
- KPI Cards (Sales, Profit, Quantity, AOV)
- Profit Trend by Month
- Sales by State
- Category & Sub-Category Analysis
- Payment Mode Distribution
- Top Customers

---

## 📌 Key Insights
- Maharashtra contributes the highest sales
- Printers and Bookcases generate maximum profit
- COD is the most used payment method
- Profit shows strong growth in year-end months

---

## 📂 Dataset
The dataset represents e-commerce order details including:
- Order Date
- Customer Name
- State
- Category & Sub-Category
- Payment Mode
- Sales, Profit, Quantity
